# Интеграция Kaspersky Endpoint Security

Сценарий `KES.ps1` ожидает следующую локальную структуру:

```text
KES/
├── KES.ps1
├── ActivationCode.txt       # одна строка с кодом, не публиковать
└── KES/
    └── setup_kes.exe
```

Установщик и код активации не входят в репозиторий. `ActivationCode.txt` исключён через `.gitignore`. Получите дистрибутив и лицензию из официального источника вашей организации.
