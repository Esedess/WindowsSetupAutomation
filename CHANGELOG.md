# История изменений

## 2.0.2

- Разрешён запуск EXE без аргументов командной строки.
- Пустой `ArgumentList` больше не передаётся в `Start-Process`.

## 2.0.1

- `ActivationCode.txt` для KES стал необязательным.
- Добавлена поддержка кода активации из `setup.ini` распакованного установщика KES.

## 2.0.0

- Новый автономный интерфейс PowerShell/WinForms.
- Конфигурация приложений и сценариев через GUI.
- Редактируемая очередь выполнения.
- Разделение активации, системных настроек и антивируса.
- Ручной запуск и настраиваемый таймер.
- Поддержка запуска с ISO в режиме только чтения.
- Маски версий установщиков и контроль кодов завершения.
- Итоговое окно и общий журнал установки.
