# Каталог приложений

Помещайте каждый дистрибутив в отдельную подпапку, например:

```text
apps/
└── 7-Zip/
    └── 7z2501-x64.exe
```

После этого добавьте запись через интерфейс. Абсолютные пути и выбор файлов вне `apps` запрещены. Дистрибутивы исключены из Git с помощью `.gitignore` и не должны публиковаться без разрешения правообладателя.

- `ExampleInstall.ps1` показывает короткую универсальную PowerShell-обёртку.
- `Telegram.example.ps1` — более живой пример: маска версии, несколько ключей, логирование и создание ярлыка после установки.
