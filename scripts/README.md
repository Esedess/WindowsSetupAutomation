# Системные сценарии

- `Firewall.ps1` отключает профили Windows Firewall штатной командой `netsh advfirewall`.
- `UAC.ps1` переводит UAC в режим «Всегда уведомлять».
- `Defender.ps1` — интеграционная обёртка; требует отдельно загруженный Windows Defender Remover и изменённый `removeantivirus.bat` без принудительной перезагрузки.
- `WindowsUpdate.ps1` — интеграционная обёртка для Windows Update Blocker 1.8.

Ожидаемая структура сторонних компонентов описана в основном README. Все действия безопасности по умолчанию выключены. Проверяйте сценарии в виртуальной машине перед применением.
